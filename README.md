## 🚀 Projetos em destaque

### 🎓 Arxio — Plataforma Acadêmica Colaborativa

Plataforma acadêmica em desenvolvimento para **compartilhamento de conhecimento, projetos,
estudos e produções acadêmicas** entre estudantes, professores e a comunidade universitária.

**Principais funcionalidades:**

- 👤 Criação de perfis acadêmicos
- 📝 Publicação de artigos, estudos e projetos
- 💬 Interações por comentários, curtidas e salvamentos
- 👥 Acompanhamento de estudantes, professores e autores
- 🏷️ Organização de conteúdos por categorias e tags
- 🔐 Autenticação e gerenciamento de usuários
- 🤝 Desenvolvimento colaborativo em equipe

O projeto está atualmente em fase de **MVP** e é desenvolvido no contexto da disciplina
de Engenharia de Software.

**Tecnologias:**

`TypeScript` `Express` `Prisma` `PostgreSQL` `Zod` `JWT`

---

### 💰 Expense API — API de Finanças Pessoais

API REST em desenvolvimento para **gerenciamento de finanças pessoais**, criada como
projeto prático de backend utilizando Python e banco de dados NoSQL.

**Principais características:**

- ⚡ API REST desenvolvida com FastAPI
- 🍃 Persistência de dados com MongoDB
- 🐳 MongoDB executado em containers com Docker Compose
- 🗄️ Mongo Express para administração do banco de dados
- 📚 Documentação automática utilizando Swagger/OpenAPI
- 📦 Gerenciamento de dependências e ambiente com uv

**Tecnologias:**

`Python` `FastAPI` `MongoDB` `Docker` `REST API` `uv`
