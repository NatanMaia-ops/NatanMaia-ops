## Projetos em destaque

<br>

**Clinical RAG Assistant**
Assistente clínico experimental, desenvolvido em equipe, que processa documentos PDF e responde perguntas com base nos trechos recuperados, apresentando documento e página como fonte. Implementa ingestão e limpeza de texto, chunking, geração de embeddings, indexação no ChromaDB, recuperação semântica e geração de respostas com Llama 3.1 via Ollama. Inclui interface Streamlit, testes automatizados e avaliação de fidelidade e relevância do RAG.

`Python` `RAG` `LLMs` `Embeddings` `ChromaDB` `Ollama` `Streamlit`
→ [Ver repositório](https://github.com/cleidyanne-castro/clinical-rag-assistant)

<br>

**Concierge ConectaTel**
Assistente de atendimento com pipeline Medallion, RAG sobre documentos oficiais, filtro de vigência, decisões de resposta ou escalonamento e trilha de auditoria por `trace_id`. Arquitetura integrando processamento de dados no Databricks, embeddings, busca vetorial e serviços AWS como Bedrock, AgentCore, Lambda, API Gateway, S3, DynamoDB e CloudWatch.

`Python` `Engenharia de Dados` `RAG` `Databricks` `Amazon Bedrock` `AWS` `Docker`
→ [Ver repositório](https://github.com/cleidyanne-castro/concierge-conectatel)

<br>

**Assistente de Triagem Pix**
Prova de conceito de IA generativa para triagem inicial de solicitações relacionadas ao Pix, com respostas fundamentadas em documentos públicos, controles de segurança e encaminhamento para análise humana. Contribuição focada no levantamento da estrutura de rede e dos controles de comunicação necessários para a solução em ambiente AWS.

`AWS` `Arquitetura de Redes` `Segurança em Nuvem` `IA Generativa` `Amazon Bedrock`
→ [Ver repositório](https://github.com/cleidyanne-castro/aws-digital-bank-triage-assistant)

<br>

**Expense API**
API REST para gerenciamento de finanças pessoais, com operações CRUD, filtros, resumo de receitas e despesas, documentação OpenAPI e persistência em MongoDB.

`Python` `FastAPI` `MongoDB` `Docker` `REST API`
→ [Ver projeto](https://github.com/NatanMaia-ops/expense_api)

<br>

**Arxio**
MVP colaborativo para publicação e interação com conteúdos acadêmicos, incluindo gerenciamento de usuários, validação de dados e autenticação JWT.

`TypeScript` `Express` `Prisma` `PostgreSQL` `JWT`
→ [Ver projeto](https://github.com/NatanMaia-ops/Arxio-)
