## Projetos em destaque

### 🩺 Clinical RAG Assistant

Assistente clínico experimental que processa documentos PDF e responde perguntas com base nos trechos recuperados, apresentando o documento e a página utilizados como fonte.

O projeto implementa ingestão e limpeza de texto, chunking, geração de embeddings, indexação no ChromaDB, recuperação semântica e geração de respostas com o Llama 3.1 executado localmente via Ollama. Também inclui interface Streamlit, testes automatizados e avaliação de fidelidade e relevância do RAG.

`Python` `RAG` `LLMs` `Embeddings` `ChromaDB` `Ollama` `Streamlit`

### 📡 Concierge ConectaTel

Assistente de atendimento com pipeline Medallion, RAG sobre documentos oficiais, filtro de vigência, decisões de resposta ou escalonamento e trilha de auditoria por `trace_id`.

A arquitetura integra processamento de dados no Databricks, embeddings, busca vetorial e serviços AWS como Bedrock, AgentCore, Lambda, API Gateway, S3, DynamoDB e CloudWatch.

`Python` `Engenharia de Dados` `RAG` `Databricks` `Amazon Bedrock` `AWS` `Docker`

[Ver projeto](https://github.com/cleidyanne-castro/concierge-conectatel)

Minha contribuição foi o levantamento da estrutura de rede e dos controles de comunicação necessários para a solução em ambiente AWS.
